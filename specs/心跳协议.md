# 心跳协议

## 上行协议

```json
{
    "ptype"   : "client_heartbeat",
    "id": "heartbeat-123",
    "from": {
        "app": "example_chat.customer",
        "pin": "12342",
        "clientType": ""
    },
    "to": {
        "app": "example.chat"
    },
    "body": {},
    "ver": "1.0",
    "timestamp": 1769063279098
}
```

V4.0 `client_heartbeat` 成功下行

```json
{
    "ptype": "ack",
    "id": "bced3b54-1d08-cd89-c596-c85c517fb65f", // 和上行协议ID一致
    "body": {
        "type": "client_heartbeat" // 对应上行请求的协议类型
    }
}
```

## 下行协议

`client_heartbeat` 成功下行
```json
{
    "id": "bced3b54-1d08-cd89-c596-c85c517fb65f", // 和上行协议ID一致
    "ptype": "ack",
    "body": {
        "type": "client_heartbeat" // 对应上行请求的协议类型，与上行请求的 ptype 保持一致
    },
    "ver": "1.0",
    "timestamp": 1769063279192
}
```
