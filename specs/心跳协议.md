# 心跳协议

实时文档见 https://kylith.atlassian.net/wiki/spaces/m78rqGL1Q4UV/pages/389808951

## 上行协议

```json
{
    "type"   : "* client_heartbeat"
    // 空 body
}
```

V4.0 `client_heartbeat` 成功下行

```json
{
    "type": "* client_heartbeat",
    "body": { }
}
```

## 下行协议

`client_heartbeat` 成功下行
```json
  {
    "id": "bced3b54-1d08-cd89-c596-c85c517fb65f" // 和上行协议ID一致
    "type": "ack",
    "body": {
        "type" : "* client_heartbeat（对应上行请求的协议类型，与上行请求的type保持一致）",
    }
  }
```
