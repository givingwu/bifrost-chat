# 会话列表

实时文档见 https://kylith.atlassian.net/wiki/spaces/m78rqGL1Q4UV/pages/390660303

## 接口地址

`/bifrost-hermod/chat/list`

## 接口参数

```
app : fox_collect.waiter
pin : 134324 // 抽象的 uid
clientVersion : 2.0.0
current : 1 // 当前页
pageSize : 20 // 每页条数
```

## 列表返回
```ts
{
 "code" : 0,
 "data" : [{
      "newUnreadCount": true, // Boolean 是否存在未读
      "app" : "fox_collect.waiter",
      "sid" : "56ed75a3d2071545fec7409a8c855b1c", // session ID<uuid> 格式
      "pin" : "435345",
      "name" : "username",
      "subjectId" : "资产id" 
      "time" : 1768984512862 // 最后一条消息的时间
      "lastMessage": { Packet } // 最后一条消息 
 }]
}
```
