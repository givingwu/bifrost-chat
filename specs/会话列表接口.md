# 会话列表

实时文档见 https://kylith.atlassian.net/wiki/spaces/m78rqGL1Q4UV/pages/390660303

## 接口地址

`/bifrost-hermod/chat/list`

## 接口参数

```
app : fox_collect.waiter
pin : 134324 // 抽象的 uid
clientVersion : 2.0.0
current : 1 // 当前页
pageSize : 20 // 每页条数
```
