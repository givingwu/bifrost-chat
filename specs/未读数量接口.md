# 未读数量接口

实时文档见 https://kylith.atlassian.net/wiki/spaces/m78rqGL1Q4UV/pages/466814570

## 接口地址

`/bifrost-hermod/chat/unread`

## 接口参数

```json
{
 "app" :"fox_collect.waiter", // 当前应用 ID
 "pin" : "324354", // 当前用户的 ID
 "channelType" :"2345345", // 非必填
 "chatId" "fafda"    // 非必填
}
```

## 接口返回

```json
{
 "code" : 0,
 "data" :{
   "sms" : 23424,
   "whatapp" : 3423
  }
}
```
