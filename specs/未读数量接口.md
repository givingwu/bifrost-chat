# 未读数量接口

## 接口地址

`/messaging/chat/unread`

## 接口参数

```json
{
 "app" :"example_chat.waiter", // 当前应用 ID: string
 "pin" : "324354", // 当前用户的 ID: string
 "channelType" :"2345345", // 非必填: string
 "chatIds" ["chat-a-1", "chat-a-2", "chat-b-1", "chat-c-1"]    // 非必填: string[]
}
```

## 接口返回

```json
{
 "code" : 0,
 "data" : {
   "sms" : 23424,
   "whatapp" : 3423
  }
}
```
