# 类型声明

实时文档见 https://kylith.atlassian.net/wiki/spaces/m78rqGL1Q4UV/pages/393085118

> **重要说明：**
> - **ptype**（协议类型）：必填字段，用于标识协议层面的消息类型，聊天消息统一使用 `chat_message`
> - **body.type**（内容类型）：消息内容的类型（如 `text`、`image`、`video`、`file`、`template` 等）

```ts
// 消息内容类型（body.type）
export type MessageContentType = 'text' | 'voice' | 'video' | 'image' | 'file' | 'template';
// 内容联合类型
export type MessageContent =
  | { text: string }
  | { url: string; mimeType: string; size?: number }
  | { templateId: string; params: Record<string, string> };
```

## 完整消息示例

```json
{
  "id": "msg-123",
  "from": {
    "app": "fox_collect.waiter",
    "pin": "agent-456"
  },
  "to": {
    "app": "fox_collect.customer",
    "pin": "customer-789"
  },
  "ptype": "chat_message",
  "body": {
    "type": "text",
    "content": { "text": "你好" }
  },
  "ver": "1.0",
  "timestamp": 1769063279192
}
```

## 文本类型
```ts
{
  ptype: "chat_message",
  body: {
    type: "text",
    content: { text: string }
  }
}
```
