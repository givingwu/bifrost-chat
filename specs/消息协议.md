## Standard Message Body 标准消息体

```ts
{
    "id": "123", // 发起方生成 uuid
    "mid": "234234", // 投递服务生成消息服务端 id
    "upid" : "234234" // 上一条消息id
    "from": { // 发送人 
        "app": "im.customer",
        "pin": "123323",  // 用户
        "clientType" : "pc",
    },
    "to": {  // 接收人
        "app": "im.waiter",
        "pin": "13214", //客服
        "clientType" : "pc"
    },
    "ptype" : "CHAT_MESSAGE", // 消息类型
    "body": {
       // 消息内容， 约定的消息格式，自定义消息，
       // 消息内容，提供固定几个模版， ack/ 撤回 这些是固定消息格式
    },
    "ver": "1.0", // 协议版本
    "timestamp": "124324242" // 服务端生成时间戳
}
```

## Type 字段枚举

```
登录：auth
聊天消息: chat_message
ack ： ack
客户端已收：msg_receive_ack
客户端已读：msg_read_ack
心跳： client_heartbeat
```

## Tenant 租户枚举

定义规则：`{业务}.{角色}`

```
催收坐席端：fox_collect.waiter / 用户：fox_collect.customer
Argus 客服客诉坐席：fox_argus.waiter / 用户：fox_argus.customer
```
