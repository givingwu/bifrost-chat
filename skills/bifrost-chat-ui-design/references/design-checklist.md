# 设计评审清单

## 1) 信息层级

- 主信息（标题/正文）与次信息（时间/状态）视觉层级是否清晰。
- 空态、加载态、错误态是否可识别。

## 2) 状态语义

- 发送态、失败态、已读态是否用统一语义色。
- 危险色与告警色是否可区分。

## 3) 可访问性

- 关键按钮是否可键盘操作。
- 文本与背景对比度是否足够。
- 图标是否仅靠颜色表达状态（若是，需要补文字或形状）。

## 4) 跨主题一致性

- light/dark/system 下布局和间距保持一致。
- 主题切换后状态色仍可辨识。

## 5) 工程可维护性

- 是否复用现有组件与类名约定。
- 是否将颜色/间距提取到 token。
